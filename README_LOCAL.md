# Запуск БЕЗ Docker

## Что нужно установить (один раз)

1. **Python 3.11+** — https://python.org/downloads  
   ⚠️ При установке отметь галку **"Add Python to PATH"**

2. **Node.js 20+** — https://nodejs.org  
   Скачивай версию **LTS**

## Запуск (каждый раз)

### Первый раз — установи зависимости:
```
install.bat
```

### Запуск приложения:
```
start.bat
```

Откроются два окна (бэкенд и фронтенд), и через ~8 секунд автоматически откроется браузер на http://localhost:3000

## Что изменилось по сравнению с Docker-версией

- Вместо PostgreSQL используется **SQLite** (файл `backend/transport.db`)  
  База создаётся и заполняется автоматически при первом запуске — ничего устанавливать не нужно
- Не нужен Docker Desktop
- Запуск через `start.bat` вместо `docker compose up`

---

## Если что-то не работает

**Ошибка "python не является командой"** — переустанови Python с галкой "Add to PATH" и перезапусти PowerShell/CMD

**Ошибка "node не является командой"** — переустанови Node.js и перезапусти терминал

**Фронтенд не открывается** — подожди 30-60 секунд, Nuxt собирается не мгновенно

**Ошибка CORS / нет данных** — убедись что окно Backend не закрыто и в нём нет ошибок
