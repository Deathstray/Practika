# 🚌 Система диспетчеризации служебного транспорта

Веб-приложение для управления служебным транспортом предприятия.  
Три роли: **Сотрудник** (подаёт заявки) · **Диспетчер** (управляет) · **Водитель** (выполняет поездки)

---

## 🚀 Способ 1 — Запуск через Docker (рекомендуется)

> Не нужно устанавливать Python, Node.js или PostgreSQL — всё внутри Docker

### Что нужно установить

**Docker Desktop** → https://www.docker.com/products/docker-desktop/  
После установки — **запусти Docker Desktop** и дождись пока иконка 🐳 в трее перестанет анимироваться

### Запуск

```bash
# 1. Клонируй репозиторий
git clone https://github.com/Deathstray/Practika.git
cd Practika

# 2. Запусти (первый раз ~5-10 минут, скачиваются образы)
docker compose up --build
```

### Готово! Открывай в браузере:

| Сервис | Адрес |
|--------|-------|
| 🌐 Приложение | http://localhost:3000 |
| 📖 API документация | http://localhost:8000/docs |

### Остановка

```bash
# Остановить
docker compose down

# Остановить и удалить все данные (сброс БД)
docker compose down -v
```

## 🛠️ Способ 2 — Запуск без Docker

> Для тех у кого не работает Docker

### Что нужно установить

| Программа | Ссылка | Важно |
|-----------|--------|-------|
| **Python 3.11+** | https://python.org/downloads | ⚠️ При установке отметь **"Add Python to PATH"** |
| **Node.js 20 LTS** | https://nodejs.org | Скачивай версию **LTS** |

### Шаг 1 — замени файлы

Скачай архив **[no-docker-patch.zip](../../raw/main/no-docker-patch.zip)** из репозитория и скопируй файлы поверх существующих в папку проекта.

Что изменится: вместо PostgreSQL будет использоваться **SQLite** (файл создаётся автоматически, ничего устанавливать не нужно).

### Шаг 2 — установи зависимости (один раз)

Дважды кликни на файл:
```
install.bat
```

### Шаг 3 — запускай каждый раз

Дважды кликни на файл:
```
start.bat
```

Откроются два окна (бэкенд и фронтенд) и через ~10 секунд браузер откроется автоматически на http://localhost:3000

| Логин | Роль | Что может делать |
|-------|------|-----------------|
| `dispatcher` | 📋 Диспетчер | Принимать/отклонять заявки, назначать водителей, смотреть статистику |

## ⚙️ Функциональность

### Этап 1 — Фундамент ✅
- Регистрация и вход с JWT-токеном
- Разграничение по ролям — каждый попадает в свой интерфейс
- CRUD справочников: водители и автомобили

### Этап 2 — Заявки ✅
- Форма создания заявки (откуда, куда, дата, цель, примечания)
- Диспетчер принимает или отклоняет заявку с указанием причины
- Сотрудник видит статус и причину отказа

### Этап 3 — Полный цикл поездки ✅
- Диспетчер назначает водителя и автомобиль
- Проверка занятости — нельзя назначить занятого водителя/машину
- Водитель отмечает выезд и возврат
- Сотрудник может отменить заявку пока она в статусе «Новая»

### Этап 4 — История и управление ✅
- История поездок с фильтрами по дате, водителю, статусу
- Справочник часто используемых адресов с автодополнением
- Экспорт истории в Excel

### Этап 5 — Дашборд и аналитика ✅
- Дашборд: активные поездки, свободные водители, новые заявки — всё на одном экране
- Статистика за период: топ маршрутов, загруженность водителей
- Графики (ECharts): динамика заявок по дням

## ❓ Решение проблем

**Docker: `open //./pipe/dockerDesktopLinuxEngine`**  
→ Docker Desktop не запущен. Найди его в меню Пуск и запусти, подожди пока иконка 🐳 в трее перестанет анимироваться

**Docker: сборка зависает надолго**  
→ Это нормально при первом запуске (скачиваются образы ~500 МБ). Просто жди

**`python` не является командой / `node` не является командой**  
→ Переустанови Python/Node с галкой "Add to PATH" и **перезапусти терминал**

**Фронтенд не открывается сразу**  
→ Подожди 30–60 секунд — Nuxt собирается не мгновенно. Обнови страницу
