# 🚌 Система диспетчеризации служебного транспорта

Веб-приложение для управления служебным транспортом предприятия.  
Три роли: **Сотрудник** (подаёт заявки) · **Диспетчер** (управляет) · **Водитель** (выполняет поездки)

---

## 👤 Демо-аккаунты

> Пароль у всех: **`admin123`**

| Логин | Роль | Что может делать |
|-------|------|-----------------|
| `dispatcher` | 📋 Диспетчер | Принимать/отклонять заявки, назначать водителей, смотреть статистику |
| `employee1` | 👤 Сотрудник | Подавать заявки на транспорт, отслеживать их статус |
| `driver1` | 🚗 Водитель | Видеть назначенные поездки, отмечать выезд и возврат |

## 🚀 Способ 1 — Запуск через Docker (рекомендуется)

> Не нужно устанавливать Python, Node.js или PostgreSQL — всё внутри Docker

### Шаг 1 — Установи Docker Desktop

Скачай и установи: https://www.docker.com/products/docker-desktop/

После установки **запусти Docker Desktop** и дождись пока иконка 🐳 в трее станет неподвижной.

> ⚠️ Если Docker Desktop не запущен — команды не будут работать!

### Шаг 2 — Клонируй репозиторий

```bash
git clone https://github.com/Deathstray/Practika.git
cd Practika
```

Или скачай ZIP с GitHub → распакуй → открой терминал в папке `Practika`

### Шаг 3 — Запусти

```bash
docker compose up --build
```

⏳ **Первый запуск занимает 5–15 минут** — скачиваются образы и зависимости. Просто жди.

### Шаг 4 — Открой в браузере

Когда в терминале появится:
```
backend-1  | INFO: Application startup complete.
frontend-1 | Listening on http://0.0.0.0:3000
```

Открывай: **http://localhost:3000**

> ⚠️ Не открывай `0.0.0.0:3000` — это не работает! Только `localhost:3000`

### Остановка

```bash
# Остановить (данные сохранятся)
docker compose down

# Полный сброс включая базу данных
docker compose down -v
```

### Повторный запуск

```bash
docker compose up
```

(без `--build` — быстрее, т.к. образы уже собраны)

## 🛠️ Способ 2 — Запуск без Docker

> Если Docker не удаётся запустить

### Что нужно установить

| Программа | Ссылка | Важно |
|-----------|--------|-------|
| **Python 3.11+** | https://python.org/downloads | ⚠️ При установке отметь **"Add Python to PATH"** |
| **Node.js 20 LTS** | https://nodejs.org | Скачивай версию **LTS** |

### Настройка файлов

Замени 3 файла в проекте на версии для локального запуска (SQLite вместо PostgreSQL):

- `backend/config.py` — переключает базу данных на SQLite  
- `backend/database.py` — убирает зависимость от PostgreSQL  
- `backend/main.py` — убирает импорт psycopg2  

Эти файлы есть в архиве `no-docker-patch.zip` в репозитории.

### Установи зависимости (один раз)

Дважды кликни:
```
install.bat
```

### Запускай каждый раз

Дважды кликни:
```
start.bat
```

Откроются два окна (бэкенд и фронтенд), через ~20 секунд браузер откроется автоматически на **http://localhost:3000**

## ❓ Частые проблемы

### ❌ `open //./pipe/dockerDesktopLinuxEngine` при запуске Docker

**Причина:** Docker Desktop не запущен  
**Решение:** Найди Docker Desktop в меню Пуск → запусти → подожди пока иконка 🐳 в трее перестанет анимироваться

---

### ❌ Сборка зависает надолго

**Это нормально при первом запуске.** Скачивается ~500 МБ зависимостей. Просто жди.

---

### ❌ `localhost:3000` — страница недоступна

**Причина:** Фронтенд ещё не поднялся  
**Решение:** Подожди пока в терминале не появится `Listening on http://0.0.0.0:3000`, затем обнови страницу

---

### ❌ Неверные учётные данные при входе

**Причина:** Старая база данных с неправильными паролями  
**Решение:**
```bash
docker compose down -v
docker compose up --build
```
Флаг `-v` удаляет старую базу — она создастся заново с правильными паролями

---

### ❌ `python не является командой` / `node не является командой`

**Причина:** Программа установлена без добавления в PATH  
**Решение:** Переустанови Python/Node с галкой **"Add to PATH"** → перезапусти терминал

---

### ❌ Нет бокового меню после входа

**Причина:** Старые файлы layouts без верстки  
**Решение:** Скопируй файлы из `fix3.zip` (есть в репозитории):
```
frontend/layouts/dispatcher.vue
frontend/layouts/employee.vue  
frontend/layouts/driver.vue
```
Затем `docker compose down -v && docker compose up --build`

## 📋 Функциональность

### Этап 1 — Фундамент ✅
- Регистрация и вход с JWT-токеном
- Три роли с отдельными интерфейсами и боковой навигацией
- CRUD справочников: водители и автомобили

### Этап 2 — Заявки ✅
- Форма создания заявки (откуда, куда, дата/время, цель, примечания)
- Диспетчер принимает или отклоняет с указанием причины
- Сотрудник видит статус и причину отказа в реальном времени

### Этап 3 — Полный цикл поездки ✅
- Диспетчер назначает водителя и автомобиль на принятую заявку
- Проверка занятости — нельзя назначить занятого водителя или машину
- Водитель отмечает фактическое время выезда и возврата
- Сотрудник может отменить заявку пока она в статусе «Новая»

### Этап 4 — История и управление ✅
- История поездок с фильтрами по дате, водителю, статусу
- Справочник часто используемых адресов с автодополнением в форме
- Экспорт истории в Excel

### Этап 5 — Дашборд и аналитика ✅
- Дашборд: активные поездки, свободные водители, новые заявки одним взглядом
- Статистика за выбранный период: топ маршрутов, загруженность водителей
- Графики динамики заявок по дням (ECharts)

## 🗂️ Структура проекта

```
Practika/
├── docker-compose.yml        # Запуск всех сервисов одной командой
├── init.sql                  # Схема БД + начальные данные
├── README.md
├── backend/                  # FastAPI (Python 3.11)
│   ├── Dockerfile
│   ├── requirements.txt
│   ├── main.py
│   ├── config.py
│   ├── database.py
│   ├── models.py             # Таблицы (SQLAlchemy ORM)
│   ├── schemas.py            # Валидация данных (Pydantic)
│   ├── auth.py               # JWT авторизация
│   ├── seed.py               # Начальные данные
│   └── routers/
│       ├── auth.py           # /auth/login, /auth/register, /auth/me
│       ├── drivers.py        # CRUD водителей
│       ├── vehicles.py       # CRUD автомобилей
│       ├── orders.py         # Заявки (все роли)
│       └── extra.py          # Адреса + статистика/дашборд
└── frontend/                 # Nuxt 3 + Vue 3 (TypeScript)
    ├── Dockerfile
    ├── pages/
    │   ├── login.vue
    │   ├── register.vue
    │   ├── dispatcher/        # Дашборд, заявки, история, статистика, справочники
    │   ├── employee/          # Список заявок, форма новой заявки
    │   └── driver/            # Назначенные поездки
    ├── layouts/               # Боковая навигация для каждой роли
    ├── stores/auth.ts         # Pinia — хранение токена и данных пользователя
    ├── middleware/            # Защита роутов по ролям
    └── composables/useApi.ts  # HTTP-клиент с автоматической авторизацией
```

## 📡 API Endpoints

| Метод | Путь | Роль | Описание |
|-------|------|------|----------|
| POST | `/auth/login` | все | Вход |
| POST | `/auth/register` | все | Регистрация |
| GET | `/auth/me` | все | Текущий пользователь |
| GET/POST | `/orders/` | dispatcher/employee | Заявки |
| POST | `/orders/{id}/accept` | dispatcher | Принять заявку |
| POST | `/orders/{id}/reject` | dispatcher | Отклонить с причиной |
| POST | `/orders/{id}/assign` | dispatcher | Назначить водителя/машину |
| GET | `/orders/my` | employee | Мои заявки |
| DELETE | `/orders/{id}/cancel` | employee | Отменить заявку |
| GET | `/orders/driver/assignments` | driver | Мои назначения |
| POST | `/orders/{id}/depart` | driver | Отметить выезд |
| POST | `/orders/{id}/return` | driver | Отметить возврат |
| GET | `/orders/export/excel` | dispatcher | Экспорт в Excel |
| GET | `/stats/dashboard` | dispatcher | Данные дашборда |
| GET | `/stats/` | dispatcher | Статистика за период |
| GET | `/docs` | — | Swagger UI документация |
